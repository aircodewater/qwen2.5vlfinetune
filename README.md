# 🌟 Qwen2.5-VL 金融多模态大模型微调与部署

> **⚠️ 严正声明：** > 本项目的底层基础框架依托于优秀的开源项目 [LLaMA-Factory](https://github.com/hiyouga/LLaMA-Factory)，特此向开源社区与原作者致敬。

### 👨‍💻 个人核心贡献与业务落地：
本项目并非简单的框架拉取，而是针对金融垂直场景进行的端到端真实业务改造。本人的核心工作包括：

1. **自动化多模态数据工程：** 针对开源金融视觉语料匮乏的问题，独立编写了自动化数据流水线（位于 `data_process/` 目录），涵盖数据拉取、清洗与高密度图文问答对的构建。
2. **多模态监督微调 (SFT)：** 基于 Qwen2.5-VL-Instruct 底座，编写了针对复杂图表结构解析与逻辑推理的微调配置，显著提升了金融特征（如K线形态、放量缩量）的视觉解析准确率。
3. **工程化部署与 API 封装：** 完成了微调模型的高并发服务端部署改造，重构了图文传输链路。
